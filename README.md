# Workday Copilot

Build a modern, responsive web application called AI Workplace Productivity Assistant that helps professionals automate workplace tasks using AI.

The application should include:

Smart Email Generator: Build a dedicated email-writing workspace that helps users create high-quality emails for different professional situations.

AI Task Planner: Create an intelligent task-planning workspace that transforms goals, projects, and unstructured to-do lists into practical action plans.

AI Research Assistant: Build a professional research workspace that helps users explore topics, organize information, and prepare structured reports.

AI Chatbot Interface: Build a conversational AI workspace designed for workplace questions, brainstorming, writing assistance, problem-solving, and general productivity.   Include section to upload files as knowledge bases or sources. No backend

Requirements:

Modern dashboard UI

Sidebar navigation

Responsive design

Structured AI prompts

Editable AI outputs

Responsible AI disclaimer

The design should be clean, modern, and professional, similar to a SaaS platform. Use rainbow colours with white majority
